# 源码模式 Python 安装计划（D-004 合同）

本文件是"缺少合格 Python 时"的唯一响应形态：只展示计划，不执行安装。
获得用户明确批准前，本产品不调用任何包管理器、不下载、不提权。

## 1. 检测逻辑（H1 已随 README 声明，H2 随 CLI 落地）

- 源码模式启动时检测 `python --version` 是否 >= 3.11。
- 不合格或缺失时：输出本计划文本，退出码 2（invalid_input 类），
  绝不自动进入安装。

## 2. 拟安装内容（示例，Windows）

| 项 | 值 |
|---|---|
| 软件 | CPython 3.12.x（或当前 3.11+ 稳定版） |
| 来源 | python.org 官方安装器 或 Microsoft Store（winget 也受支持） |
| 拟执行命令 | `winget install -e --id Python.Python.3.12`（需用户批准后） |
| 网络影响 | 访问 winget/CDN 下载约 25-30 MB |
| 权限影响 | winget 可能请求 UAC；本产品不代替用户确认 UAC |
| 系统影响 | 安装到用户目录或系统 Python 目录；PATH 可能新增条目 |

## 3. 批准与拒绝语义

- 用户明确批准 → 本产品调用上述命令并在结束后复检版本。
- 用户不批准或安装失败 → 提示人工安装路径（python.org 下载页），
  本产品不重试、不修改系统、不破坏工作区。
- 最终用户优先路径 = 独立可执行包（H7 交付），不需要本计划。
